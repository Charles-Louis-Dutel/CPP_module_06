# C++ Module 06 — École 42

Projet développé en **C++98** dans le cadre du cursus de l'école 42.

Ce module approfondit les différentes conversions de types en C++, notamment les conversions explicites, la manipulation des pointeurs et l'identification des types à l'exécution.

## Exercices

- **ex00 — Conversion of scalar types :** implémentation d'une classe `ScalarConverter` permettant de convertir une valeur entre les types `char`, `int`, `float` et `double`.
- **ex01 — Serialization :** conversion d'un pointeur en entier non signé (`uintptr_t`), puis reconversion vers son type d'origine.
- **ex02 — Identify real type :** identification du type réel d'un objet à l'exécution à l'aide de `dynamic_cast`, dans une hiérarchie de classes polymorphes.

## Compétences mises en œuvre

- Programmation en C++98
- Conversions explicites (`static_cast`, `reinterpret_cast`, `dynamic_cast`)
- Manipulation des pointeurs et des adresses mémoire
- Conversion entre types numériques
- Polymorphisme et identification dynamique des types (RTTI)
- Gestion des valeurs limites et des conversions impossibles
